# Realms Sentinel

Governance health & anomaly monitoring for Solana Realms DAOs.

## Why this exists

On July 7, 2026, BonkDAO lost ~$20M in treasury funds through a malicious
governance proposal: low quorum, a single voter controlling 99.9% of
voting power, and no execution delay (timelock) configured. This project
scans the risk configuration of active Realms DAOs and monitors live
proposals to detect similar patterns before execution.
